# 0001. Narrow Centered Column and Custom EJS Shelves over Quarto Bootstrap Defaults

Quarto's built-in `about: template: trestles` and `listing: type: grid` generate full-width Bootstrap containers and heavy boxed cards that conflict with the minimalist aesthetic of `gchure.bio` and `brianhie.com/bookshelf`. We decided to constrain the entire site layout (navbar, main content, and footer) to a single centered column (`max-width: 740px`) via `custom.scss` and render the `Beyond Lab` shelves using a stripped-down custom EJS listing template (`files/includes/shelf.ejs`) rather than Quarto's default `grid` cards. This keeps YAML data authoring simple (`books.yml`, `music.yml`, `movies.yml`) while enforcing clean medium-specific proportions (`2:3` Standing Books and Movie Posters, `1:1` Album Squares) with zero visual bloat.
