# 0002. Ultra-Compact 580px Column, 12px Typography Scale, and Non-Collapsing Navbar over Quarto Bootstrap Defaults

Quarto's `cosmo` Bootstrap theme defaults to `$font-size-base: 1.1rem` (`~17.6px`), stretches `<nav class="navbar">` across `100vw`, collapses navigation into a hamburger dropdown below `992px` (`navbar-expand-lg`), and forces `.navbar .navbar-container > .navbar-brand-container { margin-right: 0 !important; }`. We decided to remain on Quarto while enforcing an ultra-compact `580px` centered column across the navbar, content, and footer (`border-bottom` clipped to `.navbar-container`), disabling navbar collapsing (`collapse: false` plus high-specificity flex overrides so the brand stays flush-left and links stay flush-right on one line at all viewport widths), scaling the left `Profile Column` to `180px`, and setting site prose to `12px` (`0.75rem`) with a compact left-bordered publication template on `Research`.
