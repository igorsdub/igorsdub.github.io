# igorsdub.github.io

Personal academic website of Igors Dubanevics, built with Quarto and published through GitHub Pages.

Pushes to `main` trigger the GitHub Actions workflow, which renders and publishes the site to the `gh-pages` branch.

This site is based on `quarto-academic-website`, an MIT-licensed adaptation of [Dr. Gang He’s Quarto Academic Website Template](https://github.com/drganghe/quarto-academic-website-template). The upstream license and attribution are retained.
