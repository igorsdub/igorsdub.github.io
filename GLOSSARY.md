# Personal Shelf

Domain language for the curated media gallery and bibliographic catalogue on the personal website.

## Language

**Shelf**:
A curated grid of cultural media items (books, music, or films) rendered visually on the personal page.
_Avoid_: Gallery, media board, catalog page, listicle

**Sub-shelf**:
A thematic subdivision within a top-level media shelf grouping items by discipline or format.
_Avoid_: Category, sub-gallery, section, collection, bucket

**Curator Note**:
A concise one-sentence reflection on a media item presented as an interactive tooltip annotation.
_Avoid_: Review, synopsis, blurb, summary, description

**Master Reference Catalogue**:
The definitive reference document in the data directory recording full bibliographic citations, editions, image provenance, and annotations for all catalogued items.
_Avoid_: Bibliography, inventory list, source sheet, index
